## 어떻게 동작하나요?

1. 이미지를 240×160으로 줄이고 흑백으로 바꿉니다.
2. **윤곽선** 모드는 Sobel 필터로 경계를, **채우기** 모드는 어두운 영역을 뽑습니다.
3. 4×4 픽셀을 핀 하나로 묶어 60×40으로 줄이고, 선 굵기와 외톨이 핀 제거를 적용합니다.
4. 2×4 핀을 한 셀(1바이트)로 묶어 30×10 셀, 600자리 Dot Pad hex로 내보냅니다.

실제 연구에서는 이 단순한 변환 대신 객체 검출, 레이어 분리, 생성 모델로 *의미 있는 정보만* 남깁니다. [Dot Webtoon](/projects/dot-webtoon/), [TGM](/projects/tgm/), [Dot Pacman](/projects/dot-pacman/)을 참고하세요.
