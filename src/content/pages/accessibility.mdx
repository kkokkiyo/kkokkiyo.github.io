시각장애인 접근성을 연구하는 사람의 사이트인 만큼, 이 사이트 자체도 누구나 쓸 수 있도록 만들고 있습니다.

## 적용한 것

* 모든 페이지에 **본문으로 건너뛰기** 링크와 의미에 맞는 제목 구조(h1→h2→h3)
* 키보드만으로 모든 기능 사용 가능, 포커스 위치를 굵은 테두리로 표시
* 상단 **Aa** 메뉴에서 다크 모드, 글자 크기(최대 125%), 고대비 모드 선택. OS의 다크 모드와 대비 설정을 기본값으로 따름
* 모든 이미지에 내용을 설명하는 대체 텍스트. 비교 슬라이더는 방향키로 조작
* [Playground](/playground/)의 핀 캔버스는 방향키로 이동하고 스페이스로 핀을 올리거나 내림. 결과를 8점 점자 텍스트로도 제공
* 자동 검사 도구(axe-core)로 WCAG 2.1 AA 위반 항목을 점검

## 알려진 한계

* Playground의 이미지 변환 결과는 시각적 캔버스가 중심이라, 스크린 리더에서는 핀 개수와 점자 텍스트로만 전달됩니다.
