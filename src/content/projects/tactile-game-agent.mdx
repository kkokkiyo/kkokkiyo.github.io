## 왜 시작했나

카드 게임 화면에는 손패, 체력, 필드 위 하수인 같은 정보가 가득한데, 스크린 리더는 이걸 거의 읽지 못합니다. 화면에 뭐가 어디 있는지 알 수 없으니 게임을 할 수가 없습니다.

## 어떻게 만들고 있나

화면 인식(OCR, OmniParser, SAM2), 게임 로그, 게임마다 따로 만든 어댑터에서 정보를 모아 하나의 게임 상태로 합칩니다. 상태를 담는 틀은 공통 스키마로 따로 정의해 두어서, 게임이 바뀌어도 그대로 쓸 수 있게 했습니다.

에이전트가 대신 게임을 해 주는 건 목표가 아닙니다. 사용자가 직접 판단하고, 사용자가 확인한 행동만 제한적으로 실행하도록 설계했습니다. 실제 하스스톤 로그를 재생하고 스크린샷과 맞춰 보면서 이 흐름이 제대로 도는지 확인했습니다.

## 다음에 할 일

처음에는 하스스톤에서만 잘 돌아가면 된다고 생각했습니다. 그런데 만들다 보니 다른 게임에도 쓸 수 있는 틀로 넓히고 싶어졌습니다. 로그나 API가 없는 게임도 많아서, 결국 화면만 보고 물체의 위치와 상태를 알아내는 방법이 필요합니다. 그래서 직접 만든 팩맨 게임으로 먼저 작게 실험하고 있습니다([Dot Pacman](/projects/dot-pacman/)).
